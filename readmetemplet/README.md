## 프로젝트 소개

- Spring mvc를 이용한 커뮤니티 프로젝트
- 회원등급을 정하여 레벨별로 회원관리 가능
 (ex: 1등급 일반회우너 2등급 우수회원 ...
  99등급 관리자)
- 관리자가 게시판 메뉴를 동적으로 생성
- 게시판 종류 역시 스킨에 따라 동적으로 생성
- 게시판 종류는 갤러리, 일반 게시판, 답글기능 추가, 댓글기능 추가, 기사게시판 등..
- 각각의 게시판은 회원 등급별로 읽고 쓰는 권환을 정할 수 있음
